# Importing the Certificates into STRUST

**Demonstration · 1 minute 1 second**

This demonstration shows how to import the exported GitHub CA certificates into SAP transaction `STRUST` to establish the trust relationship required for abapGit to connect to GitHub over HTTPS. It covers opening the correct SSL client identity, adding the certificate to the certificate list and saving the trust configuration. The trust configuration shown is specific to the recorded environment; follow your organisation's certificate-management process and consult your IT and security team before applying changes to your system.
