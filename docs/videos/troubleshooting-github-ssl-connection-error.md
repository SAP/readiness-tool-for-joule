# Recognising the GitHub SSL Connection Error

**Demonstration · 20 seconds**

This demonstration shows how the GitHub SSL connection error appears in abapGit when the system does not trust the remote certificate. Recognising this error correctly is the starting point for the certificate trust remediation process described in the troubleshooting guide. The error shown is specific to the recorded environment; the exact message may differ depending on your SAP landscape and network configuration.
