# DrJoule Project Comprehensive Summary                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                               
## Project Overview                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                               
**DrJoule** is an SAP Fiori LaunchPad (FLP) plugin built with SAPUI5 that provides a capabilities overview and diagnostic tool for SAP Joule integration. It is designed as a Component.js-based application with a single XML fragment (no separate view file+
s).                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                               
**Tech Stack:**                                                                                                                                                                                                                                                
- SAPUI5 version 1.136.0+                                                                                                                                                                                                                                      
- OData V2 service (ZAPI_JOULECAPABILITY_O2)                                                                                                                                                                                                                   
- SAP FLP plugin pattern                                                                                                                                                                                                                                       
- JSON models for client-side state management                                                                                                                                                                                                                 
- No routing/views — all UI content in a single NavContainer fragment                                                                                                                                                                                          
                                                                                                                                                                                                                                                               
**How to Run:**                                                                                                                                                                                                                                                
- `npm run start-s47-local` — Local SAPUI5 libs + S47 backend proxy **(main dev command)**                                                                                                                                                                     
- `npm run start-s47` — CDN SAPUI5 libs + S47 backend proxy                                                                                                                                                                                                    
- `npm run start-local` — Local SAPUI5 + local backend                                                                                                                                                                                                         
- `npm run start-mock` — Mock server                                                                                                                                                                                                                           
- `npm run build` — Production build to `/dist`                                                                                                                                                                                                                
- `npm run deploy` — Build + deploy (ui5-deploy.yaml)

## Architecture                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                               
### Entry Point: Component.js                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                               
The app extends `UIComponent`. No views — Component opens a single fragment as a dialog and orchestrates everything:                                                                                                                                           
1. Model creation and lifecycle                                                                                                                                                                                                                                
2. OData reads via `_getEntitySPath()` + `oModel.read(path, {filters, success, error})`                                                                                                                                                                        
3. Navigation between NavContainer pages                                                                                                                                                                                                                       
4. User context switching (simulation mode)                                                                                                                                                                                                                    
5. Data filtering and search                                                                                                                                                                                                                                   
6. Joule Web Client plugin integration                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                               
### Fragment: CapabilitiesOverviewUXAPNew.fragment.xml                                                                                                                                                                                                         
                                                                                                                                                                                                                                                               
Single fragment with a `Dialog > NavContainer` housing five pages:                                                                                                                                                                                             
                                                                                                                                                                                                                                                               
| Page | Description |                                                                                                                                                                                                                                         
|---|---|                                                                                                                                                                                                                                                      
| `pageMain` | Capabilities list with ObjectPageLayout, donut charts, segmented filters, search |                                                                                                                                                              
| `pageScenario` | Scenarios list for selected capability; same layout; rating indicators in header |                                                                                                                                                          
| `pageScenarioDetail` | Scenario detail: 4 summary cards + APIs table + Target Mappings table |                                                                                                                                                               
| `pageDetail` | **Legacy hardcoded page** — not data-bound, not actively used |                                                                                                                                                                               
| `promptLibraryPage` | TreeTable of Joule prompt categories with Play/Edit buttons |                                                                                                                                                                          
                                                                                                                                                                                                                                                               
### Models in Use                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                               
| Model Name | Type | Purpose |                                                                                                                                                                                                                                
|---|---|---|                                                                                                                                                                                                                                                  
| `capabilitiesModel` | OData (manifest) | Main service; used for all `oModel.read()` calls |                                                                                                                                                                  
| `appConfigModel` | JSON | UI state: simulationMode, selecteContextUserName, switchUserEnabled, etc. |                                                                                                                                                        
| `capabilitySummaryModel` | JSON | Donut chart stats for pageMain |

## OData Service                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                               
**Base URL:** `https://tdclv1000183.tdc.net.sap:44303/sap/opu/odata/sap/ZAPI_JOULECAPABILITY_O2/`                                                                                                                                                              
                                                                                                                                                                                                                                                               
**Service Type:** OData V2 — CDS views + custom RAP entities                                                                                                                                                                                                   
                                                                                                                                                                                                                                                               
### ENTITY_USAGE Constants + _getEntitySPath()                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                               
`_getEntitySPath(sUsagePattern, oParams)` returns `{ path: string, filters: Filter[] }`.                                                                                                                                                                       
                                                                                                                                                                                                                                                               
All callers do: `oModel.read(oPath.path, { filters: oPath.filters, success, error })`.                                                                                                                                                                         
                                                                                                                                                                                                                                                               
Context user is read from `appConfigModel>/selecteContextUserName`. When set, the "U" entity variants are used.                                                                                                                                                
                                                                                                                                                                                                                                                               
| ENTITY_USAGE key | No-context path | With-context path |                                                                                                                                                                                                     
|---|---|---|                                                                                                                                                                                                                                                  
| `FETCH_CAPABILITIES` | `/Capabilities` | `/CapabilitiesU(p_context_user='X')/Set` |                                                                                                                                                                          
| `FETCH_CAPABILITY_SCENARIOS` | `/Capabilities('X')/to_Scenarios` | `/ScenariosU(p_context_user='X')/Set` + Filter(CapabilityName EQ x) |                                                                                                                     
| `FETCH_CAPABILITY_HEALTH` | `/CapabilityHealth('X')` | `/CapabilityHealthU` + Filter(ContextUser EQ x, CapabilityName EQ x) |                                                                                                                                
| `FETCH_SCENARIO_HEALTH` / `FETCH_SCENARIO_HEALTH_SUMMARY` | `/ScenarioHealth(CapabilityName='X',ScenarioName='Y')` | `/ScenarioHealthU` + 3 filters |                                                                                                        
| `FETCH_SCENARIO_APIS` | `/Scenarios(...)/to_APIs` | `/APIsU(p_context_user='X')/Set` + 2 filters |                                                                                                                                                           
| `FETCH_SCENARIO_TMS` | `/Scenarios(...)/to_TargetMappings` | `/TargetMappingsU(p_context_user='X')/Set` + 2 filters |                                                                                                                                        
| `FETCH_USERS` | `/Users` | `/Users` (always same) |                                                                                                                                                                                                          
                                                                                                                                                                                                                                                               
**Key encoding rule:** Entity key segments use `encodeURIComponent()`; `Filter` string values are passed raw.                                                                                                                                                  
                                                                                                                                                                                                                                                               
**References:** `webapp/model/ODataUrlPatterns.md` and `webapp/model/ODATA_URL_Reference.md`

## Navigation Flow                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                               
```                                                                                                                                                                                                                                                            
pageMain  ──(row click)──>  pageScenario  ──(row click)──>  pageScenarioDetail                                                                                                                                                                                 
   ^                              ^                                   |                                                                                                                                                                                        
   |                              └──────────── onNavBackToScenario ──┘                                                                                                                                                                                        
   └──────────────────────────── onNavBackToMain ─────────────────────                                                                                                                                                                                         
```                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                               
- `onCapabilityRowPress` → `_loadScenariosForCapability(capName, displayName)` → navigate to `pageScenario`                                                                                                                                                    
- `onScenarioRowPress` → `_loadScenarioDetail(capName, scenName, desc, health)` → navigate to `pageScenarioDetail`                                                                                                                                             
- `onNavBackToMain` → `oNavContainer.back()` + set `switchUserEnabled = true`                                                                                                                                                                                  
- `onNavBackToScenario` → `oNavContainer.back()` (does not re-enable switchUser)                                                                                                                                                                               
                                                                                                                                                                                                                                                               
**switchUserEnabled flag:**                                                                                                                                                                                                                                    
- `true` by default (pageMain)                                                                                                                                                                                                                                 
- Set to `false` when entering pageScenario or pageScenarioDetail                                                                                                                                                                                              
- Set back to `true` only in `onNavBackToMain`                                                                                                                                                                                                                 
- Bound to `enabled="{appConfigModel>/switchUserEnabled}"` on Switch User + Cancel Sim buttons on all pages

## Key Methods Reference                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                               
| Method | Purpose |                                                                                                                                                                                                                                           
|---|---|                                                                                                                                                                                                                                                      
| `_getEntitySPath(pattern, params)` | Returns `{path, filters}` for OData read; auto-switches to U-variant when context user set |                                                                                                                            
| `_initializeCapabilitiesDataModel()` | Loads `/Capabilities`; sets busy on dialog; calls `__adjustCapabilityModels` |                                                                                                                                        
| `__adjustCapabilityModels(oData)` | Sets new default JSONModel from results; updates summary model |                                                                                                                                                         
| `_loadScenariosForCapability(cap, display)` | Loads capability health + scenarios; navigates to pageScenario; sets switchUserEnabled=false |                                                                                                                 
| `_loadScenarioDetail(cap, scen, desc, health)` | Parallel 3-read (ScenarioHealth + APIs + TMs); navigates to pageScenarioDetail |                                                                                                                            
| `_adjustScenarioSummaryModel(results, display)` | Updates donut chart counts for pageScenario |                                                                                                                                                              
| `_adjustScenarioSummaryModel` | Updates `scenarioSummaryModel` for pageScenario donut chart |                                                                                                                                                                
| `refreshDataSet(userName)` | After user switch/cancel: reloads capabilities + current page; calls `_applyCapabilityFilters()` |                                                                                                                              
| `_applyCapabilityFilters()` | Applies search query + status filter to idCapabilitiesTable binding |                                                                                                                                                          
| `_applyScenarioFilters()` | Applies search query + status filter to idScenariosTable binding |                                                                                                                                                               
| `onSwitchUserContextDialogClose(event)` | Sets simulation mode + context user + calls refreshDataSet |                                                                                                                                                       
| `onCancelSimulation()` | Clears simulation mode + calls refreshDataSet |                                                                                                                                                                                     
| `formatter.init(bundle)` | Stores i18n bundle in module scope for use outside XML binding context |
