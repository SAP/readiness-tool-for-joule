# UI5 framework information providers                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                               
The providers in this package collect support information from the UI5 framework, e.g. versions and messages.                                                                                                                                                  
                                                                                                                                                                                                                                                               
## Provider Interface                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                               
A provider MUST confirm to the following interface:                                                                                                                                                                                                            
```js                                                                                                                                                                                                                                                          
/**                                                                                                                                                                                                                                                            
 * Create a new instance of the UI5 information provider. This constructor loads and initializes                                                                                                                                                               
 * all local information providers.                                                                                                                                                                                                                            
 * @param {sap.base.i18n.ResourceBundle} i18nBundle - I18N resource bundle, e.g. provided from i18n model.                                                                                                                                                     
 */                                                                                                                                                                                                                                                            
constructor: function(i18nBundle) {                                                                                                                                                                                                                            
},                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                               
/**                                                                                                                                                                                                                                                            
 * Get the ID of the information provider.                                                                                                                                                                                                                     
 * @returns {string} Provider ID.                                                                                                                                                                                                                              
 */                                                                                                                                                                                                                                                            
getId: function() {                                                                                                                                                                                                                                            
},                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                               
/**                                                                                                                                                                                                                                                            
 * Get the name of the information provider to be shown on the UI.                                                                                                                                                                                             
 * @returns {string} Provider name.                                                                                                                                                                                                                            
 */                                                                                                                                                                                                                                                            
getName: function() {                                                                                                                                                                                                                                          
},                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                               
/**                                                                                                                                                                                                                                                            
 * Return if the information from this provider should be shown as a table or as a form.                                                                                                                                                                       
 * @returns {boolean} Shown as a table (`true`) or as a form (`false`).                                                                                                                                                                                        
 */                                                                                                                                                                                                                                                            
isTable: function() {                                                                                                                                                                                                                                          
},                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                               
/**                                                                                                                                                                                                                                                            
 * Collect the information.                                                                                                                                                                                                                                    
 * @returns {Promise<object>} Promise resolves with the data collected by this provider.                                                                                                                                                                       
 */                                                                                                                                                                                                                                                            
collect: function() {                                                                                                                                                                                                                                          
}                                                                                                                                                                                                                                                              
```                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                               
The ID MUST be unique among information providers. The method `collect` SHOULD collect information                                                                                                                                                             
in an asynchronous way to allow parallel execution of information providers. If the method `isTable`                                                                                                                                                           
returns `true`, the data MUST be an array with objects conforming to the following interface:                                                                                                                                                                  
                                                                                                                                                                                                                                                               
```ts                                                                                                                                                                                                                                                          
{                                                                                                                                                                                                                                                              
	System: "Fiori",                                                                                                                                                                                                                                              
	Client: string,                                                                                                                                                                                                                                               
	Username: string,                                                                                                                                                                                                                                             
	Source: string,                                                                                                                                                                                                                                               
	Type: "E" | "W" | "I",                                                                                                                                                                                                                                        
	Date: Date,                                                                                                                                                                                                                                                   
	Time: Date,                                                                                                                                                                                                                                                   
	Context: string,                                                                                                                                                                                                                                              
	ErrorText: string,                                                                                                                                                                                                                                            
	MoreInfoLink: string                                                                                                                                                                                                                                          
}                                                                                                                                                                                                                                                              
```                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                               
To register the new information provider, add it as a dependency in `Ui5InformationProvider` and                                                                                                                                                               
as an argument to the `this._loadProviders(...)` call in the constructor.
