## Notes on URL encoding                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                               
| Context | Rule |                                                                                                                                                                                                                                             
|---|---|                                                                                                                                                                                                                                                      
| Entity key (in parentheses) | `ScenarioName` must be `%2F`-encoded — e.g. `manage_automatic_payments%2Fdisplay_parameters_list` |                                                                                                                            
| `$filter` string value | Raw slash is valid in OData string literals — `manage_automatic_payments/display_parameters_list` |                                                                                                                                 
| `_getEntitySPath` in Component.js | Uses `encodeURIComponent()` for key segments; passes raw values into `$filter` strings |
