## User Context Calls — Parameterized CDS Views (user: `I999997`)                                                                                                                                                                                              
                                                                                                                                                                                                                                                               
### How parameterized views work in OData V2                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                               
CDS views declared with `with parameters` are exposed by SADL as **two entity sets**:                                                                                                                                                                          
                                                                                                                                                                                                                                                               
```                                                                                                                                                                                                                                                            
/CapabilitiesU          → the Parameters entity set (entry point, takes p_context_user as key)                                                                                                                                                                 
/CapabilitiesUSet       → the actual data rows (not directly addressable, sap:addressable="false")                                                                                                                                                             
```                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                               
You always call through the Parameters entity set using the `/Set` navigation:                                                                                                                                                                                 
                                                                                                                                                                                                                                                               
```                                                                                                                                                                                                                                                            
/CapabilitiesU(p_context_user='USER')/Set                                                                                                                                                                                                                      
```                                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                               
This tells SADL: "give me all rows of CapabilitiesU where the CDS parameter p_context_user = 'USER'".                                                                                                                                                          
                                                                                                                                                                                                                                                               
Because the CDS associations between U views do **not** carry parameter forwarding (a limitation of `as select from` views), there are **no navigation properties** between U entities. Cross-entity calls use `$filter` instead of navigation.

## User Context Calls — Custom Entities with QP (user: `I999997`)                                                                                                                                                                                              
                                                                                                                                                                                                                                                               
### How custom entity U variants work                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                               
`CapabilityHealthU` and `ScenarioHealthU` are **custom entities** backed by RAP Query Providers (not parameterized CDS views). They have no `with parameters` declaration. Instead, `ContextUser` is a regular filterable field that the Query Provider reads +
from `get_as_ranges()` at runtime and passes into the health calculation logic.                                                                                                                                                                                
                                                                                                                                                                                                                                                               
This means they behave like any normal OData entity set — plain `$filter` on the URL, no `/Set` navigation needed.

## Summary — Pattern Comparison                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                               
| Type | Pattern | Navigation | User passed via |                                                                                                                                                                                                              
|---|---|---|---|                                                                                                                                                                                                                                              
| Standard CDS view | `/EntitySet` or `/EntitySet('key')/to_Nav` | Yes — full navigation chain | `sy-uname` (hardcoded) |                                                                                                                                      
| Parameterized CDS view | `/EntitySetU(p_context_user='X')/Set?$filter=...` | No — use `$filter` | CDS parameter → projected as `ContextUser` field → VE class reads it |                                                                                     
| Custom entity (QP) | `/EntitySetU?$filter=...ContextUser eq 'X'` | N/A | `ContextUser` filter field → QP reads from `get_as_ranges()` |
